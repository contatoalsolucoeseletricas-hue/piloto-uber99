# Piloto Uber / 99 (Android Kotlin v1.2)

Projeto pronto para compilar o APK **na nuvem pelo GitHub Actions** (sem instalar Android Studio no PC).
- Ajuste rápido de **R$/km** (`-0,10` / `+0,10` ou campo editável, padrão `1,40`).
- Leitura por voz e overlay de **valor da corrida**, **R$/km**, **R$/hora** e **total acumulado do dia**.
- **Filtro de Cidades** com marcação livre: **Porto Alegre, Viamão, Alvorada, Canoas, Eldorado do Sul, Guaíba, Esteio, Sapucaia do Sul, São Leopoldo, Centro, Nova Santa Rita, Montenegro e Triunfo**.
